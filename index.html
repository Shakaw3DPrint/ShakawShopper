Ativar nuvem e compartilhamento

Para compartilhar com a Jô, crie um projeto no Supabase e configure as variáveis no arquivo app.js. O arquivo supabase-schema.sql contém a estrutura inicial e as políticas de segurança.

  1. Crie um projeto no Supabase.
  2. Execute o SQL fornecido no SQL Editor.
  3. Configure URL e chave pública (anon/publishable) em app.js.
  4. Publique o site em HTTPS e crie contas separadas para vocês.

Importante: não coloque chave secreta/service_role no navegador. Esta versão inicial ainda não sincroniza com a nuvem até a configuração e integração do backend.
