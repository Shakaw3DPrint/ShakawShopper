# ShakawShopper — correção de teste

Esta versão melhora a inicialização da sincronização usando a conexão global do Supabase e mostra mensagens de erro mais claras.

## Instalação
1. Mantenha as pastas anteriores como backup.
2. Extraia este ZIP em uma pasta nova.
3. Abra CMD na pasta e execute `python -m http.server 8080` (se a porta já estiver ocupada, use a janela de servidor que já está aberta, mas navegue para a pasta correta).
4. Abra `http://localhost:8080` e entre na sua conta.

## Atenção
Esta é uma versão de diagnóstico/teste, não uma versão final. Teste primeiro com dados sem importância. Não execute o SQL novamente. A sincronização de lista ativa e orçamento precisa ser confirmada na interface antes de confiar nela. Produtos frequentes e histórico ainda não sincronizam.
